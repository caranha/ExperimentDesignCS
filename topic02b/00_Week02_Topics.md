# A simple Descriptive Experiment
## Do you even lift?

We consider a simple experiment: How much weight can we lift. How would you prepare this experiment?

### Specify the experimental question:

First, we neeed to define why we want to know this information. For the same question, different "why"s will imply in different experiments:

- Do we want to know if we have a chance to win a weight lifting competition? In this case, we want to find out the maximum possible weight we could lift.

- Do we want to know the weight we should use for a hypertrophy training? In this case, we want to find out the maximum weight we can lift 10 times in a gym, 3 times per week.

- Do we want to know what should be the weight of our emergency kit? In this case, we want to find out the maximum weight we can lift while being able to walk and do other activities, consistently.

### Clarify the observed variable.

Define precisely what data you need to collect to answer your question:
- Maximum possible weight before your muscles tire?
- Maximum speed in a bycicle ride? Or average speed?
- Performance of an algorithm in a specific data set, or any data set?

### Clarify the experiment condition

Define precisely the environment in which the experiment takes place:
- What is your condition when you start the exercise? 
- What are the weights, and what is the movement? 
- How do you measure a successful lift?

Other experiments:
- What is the route of the bycicle ride? What is the weather?
- What is the computer used to run the algorithm? What are the libraries? What is the data used?

It is important to pay attention that the combination of the observed variable and the experiment condition will affect the answer to your experimental question! 

It is an iteractive process to adjust these three questions (and others). Defining the question will help you clarify the variable and the conditions. As you clarify the variable and the conditions, you will need to reflect on the question again.

In this process, two important things to keep in mind is **curiosity** and **honesty**

## Fomalizing what we know

### Variables
- Response variable: The part of the experiment that we measure.
- Control variables: The part of the experiment that we define.
- Noise: Variation in the result of the experiment.
- Random Variable: A variable that receives a different value every time that we measure it.

### Model
The model is a mathematical explanation of the experiment.

It can be used to describe the relationship between the control and the response variable. For example, we can propose a linear model between the number of repetitions in an exercise set, and the maximum weight that we can lift.

We can also use a model to describe the range of the response variable. For example, we can propose a model that says that the time that it takes for us to ride a bycicle from the station to the university can be described by a normal distribution, with mean 10 minutes, and variance 2 minutes.

Note that the model is a map. 
- It can be wrong, 
- It can be imprecise
- It can include factors that we are not sure about.

When we design an experiment, it is important that we clarify the model that we are using in this experiment.
